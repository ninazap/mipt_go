## Домашнее задание 3:
**Реализовано:**
- Структура Budget для хранения лимитов по категориям
- Проверка бюджета при добавлении транзакции в AddTransaction
- Функция SetBudget для добавления/обновления бюджетов
- Функция LoadBudgets для загрузки бюджетов из JSON файла
- Обработка ошибок при превышении лимита и некорректном вводе

**Запуск:**
- cd ledger
- go run main.go

**Проверка:**
- Успешное добавление транзакций в пределах бюджета
- Отклонение транзакций при превышении лимита
- Валидацию суммы транзакции
- Загрузку бюджетов из файла budgets.json
